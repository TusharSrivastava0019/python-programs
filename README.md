# Python Programs Collection

A collection of beginner Python programs created as part of my coding course.

## Programs
- **factorial.py**: calculates the factorial of a number using a loop
- **fibonacci.py**: generates the Fibonacci series
- **structure_to_dict.py**: converts a list of tuples and an object into a dictionary

## How to Run
1. Install Python
2. Open a terminal in this folder
3. Run: `python factorial.py` (or any other file)
